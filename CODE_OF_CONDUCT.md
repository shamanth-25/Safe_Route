# Code of Conduct

## Our Commitment

The Safe Route project is committed to providing a welcoming, respectful, and inclusive environment for all contributors and users.

## Expected Behavior

- Be respectful and professional.
- Provide constructive feedback.
- Collaborate openly and honestly.
- Respect differing viewpoints and experiences.
- Focus on improving the project and community.

## Unacceptable Behavior

- Harassment or discrimination.
- Personal attacks or insults.
- Trolling or disruptive behavior.
- Publishing private information without consent.
- Any behavior that creates an unsafe environment.

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct and may remove contributions, comments, or participants that violate these standards.

## Scope

This Code of Conduct applies to all project spaces, including source code repositories, issue trackers, discussions, and project communications.
