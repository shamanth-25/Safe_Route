# Security Policy

## Reporting a Vulnerability

The Safe Route project takes security seriously. If you discover a security vulnerability affecting the application, please report it responsibly and privately.

When reporting a vulnerability, please include:

* A clear description of the issue
* Steps to reproduce the vulnerability
* Expected and actual behavior
* Potential impact on users or the system
* Any suggested mitigation or fix (optional)

## Scope

This policy applies to all components of the Safe Route project, including:

* Backend services
* Frontend application
* APIs
* Route analysis features
* Deployment configurations
* CI/CD pipelines

## Supported Versions

Only the latest version available in the main branch is actively maintained and supported with security updates.

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities until project maintainers have had a reasonable opportunity to investigate and address the issue.

## Security Best Practices

Contributors should:

* Never commit secrets, API keys, or credentials
* Validate user inputs appropriately
* Keep dependencies updated
* Review code for potential security risks before merging
* Follow secure coding practices during development

## Acknowledgements

We appreciate responsible security research and welcome reports that help improve the safety and reliability of the Safe Route platform.
